# SpotDeck

A minimalist Spotify-focused launcher for Android devices.

SpotDeck is a lightweight Android launcher designed for dedicated music players and audio-focused devices such as the Oilsky M308 / G88.

Instead of presenting a traditional Android home screen, SpotDeck provides a distraction-free experience centered around Spotify.

## Features

* 🎵 One-tap Spotify launch
* 🚀 Automatic Spotify startup when the launcher is displayed
* 📱 Swipe up to access installed applications
* 📝 Simple text-based application list
* ⚡ Lightweight and fast
* 🔋 Designed for low resource consumption

## User Experience

### Normal Mode

When SpotDeck becomes visible:

1. Display the home screen
2. Show the Spotify button
3. Automatically launch Spotify after a short delay

### App List Mode

Swipe up from the home screen to display installed applications.

While the application list is visible:

* Automatic Spotify launch is disabled
* Applications can be launched from the list
* Swipe down to return to the home screen

## Target Devices

* Oilsky M308 / G88
* Android-based DAPs
* Dedicated Spotify players
* Audio-focused Android devices

## Motivation

Many Android-based DAPs ship with standard launchers that provide functionality unnecessary for a dedicated music player.

SpotDeck was created to transform an Android device into a Spotify-first experience with minimal distractions and maximum simplicity.
